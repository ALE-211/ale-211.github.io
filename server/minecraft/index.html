Minecraft 1.10.2 联机教程（Age of Engineering RCMS 1.5）

服务器简介与准备工作

本服务器运行 Minecraft 1.10.2，使用自制整合包 Age of Engineering（RCMS 1.5）。所有人必须使用同一版本的整合包才能进服，否则会提示版本不符或 mod 缺失。

RCMS 1.5 更新内容：在 1.4 基础上增加了 Base 与 Clumps 两个模组。旧版 v1.4 / v1.3 仍可在 下载中心 取到，但只有 1.5 能进服。

整个联机流程共四步：装 Java → 装 PCL2 启动器 → 导入整合包 → 按你的网络情况选一种方式连接。

第一步：安装 Java 运行环境

Minecraft 1.10.2 基于 Java 8 运行，联机前必须先装好。本站提供 64 位 Java 8 安装包，直接下载安装即可。

  1. 下载 jre-8u411-windows-x64.exe，双击运行安装程序。
  2. 按向导点「下一步」直到安装完成，记住默认安装路径（通常是 C:\Program Files\Java\jre1.8.0_411）。

配置环境变量（可选步骤）

安装完成后建议配置环境变量，方便启动器和系统找到 Java（步骤整理自 Microsoft Learn 与 Oracle 官方文档）：

  1. 桌面右键「此电脑」→「属性」→ 左侧「高级系统设置」→ 弹窗右下角「环境变量」。
  2. 在下方「系统变量」区域点「新建」：
    • 变量名：JAVA_HOME（全大写、带下划线）
    • 变量值：刚才的安装路径，例如 C:\Program Files\Java\jre1.8.0_411
  3. 在系统变量里找到 Path，双击编辑，新增一条：%JAVA_HOME%\bin。
  4. 一路点「确定」关闭所有窗口。按 Win + R 输入 cmd 回车，执行 java -version
  5. 显示 java version "1.8.0_411" 类似字样即安装配置成功。

多数情况下 PCL2 启动器会自动识别已安装的 Java 8，无需手动配置；只有启动器报错找不到 Java 时，再回来按上面步骤配置。

步骤参考：Microsoft Learn: Get started with Java on Windows · JDK 安装与环境变量配置教程

第二步：下载并安装 PCL2 启动器

PCL2（Plain Craft Launcher 2）是免费的 Minecraft 启动器，绿色免安装，能管理整合包与 Java。

  1. 下载 Plain Craft Launcher 2.exe，放到固定文件夹（例如 D:\MC\），不要放桌面或 C 盘临时目录。备用版本：PCL2_CE_x64.exe。
  2. 双击运行该 exe。首次启动按提示选择游戏目录（默认即可）。
  3. 若启动器提示未找到 Java，指向上一步安装的 C:\Program Files\Java\jre1.8.0_411\bin\java.exe。

PCL2 主界面

提示：若 Windows 弹出 SmartScreen 蓝色警告，点「更多信息」→「仍要运行」即可，绿色软件常见现象。

第三步：导入 Age of Engineering 整合包

  1. 下载 Age of Engineering RCMS 1.5.zip。保持 zip 原样，不要解压。
  2. 打开 PCL2，左侧点「下载」→ 上方选「整合包」→「导入本地整合包文件」。
  3. 选中刚下载的 zip，PCL2 自动识别版本（1.10.2 + Forge）并下载游戏文件与全部 mod。
  4. 下载完成后回到「开始游戏」页，左上角版本下拉选择 Age of Engineering RCMS。
  5. 首次启动会安装所有 mod、生成世界文件，进度条走完前不要关闭窗口。

在 PCL2 中导入本地整合包

整合包 mod 较多，建议在启动器设置里把游戏内存分配调到 4098 MB ~ 6144 MB（4~6 GB），避免进游戏后卡顿崩溃。

第四步：连接服务器

先启动一次游戏进入主菜单，打开「多人游戏」。整合包里预置了一份服务器列表，里面可能有多条记录、其中一些是过期的——请只认这两条：ale211.eu.org（走 IPv6）与 26.21.59.131（走 Radmin VPN）。其余记录如果连不上，直接删掉即可，不必怀疑是自己网络的问题。

如果没有，先判断自己的网络是否支持 IPv6：浏览器打开 test-ipv6.com，页面显示 10/10 或出现 IPv6 地址即表示支持。然后按下面两种方式之一连接。

方式 A：网络支持 IPv6（推荐，延迟最低）

  1. 进入游戏主菜单 →「多人游戏」→「添加服务器」。
  2. 服务器地址填写：ale211.eu.org，名称随意。
  3. 点「完成」，双击列表中刚添加的服务器即可进服。

添加服务器

方式 B：不支持 IPv6，使用 Radmin VPN 组网

如果你所在的网络（校园网、部分家庭宽带）没有 IPv6，就用 Radmin VPN 虚拟局域网联机。你和开服的主机都要安装并加入同一个虚拟网络。

  1. 下载 Radmin_LAN_2.1.4951.1.exe，双击运行安装向导。
  2. 依次点 Next → I Agree → Install。安装中若弹出「安装虚拟网卡驱动」提示，务必选「安装」。
  3. 安装完成后启动 Radmin VPN，软件无需注册即可直接使用。
  4. 主界面顶部点菜单 Network（网络）→ Join existing network（加入现有网络）。
  5. 弹窗填写：
    • 网络名（Network name）：ALE_211（注意大写）
    • 密码（Password）：123456
  6. 加入成功后，主界面列表里会出现主机（名字含 ALE_211），后面跟着一个 26.x.x.x 形式的虚拟 IP（目前是 26.21.59.131）。
  7. 回游戏「多人游戏」→「添加服务器」，地址填这个虚拟 IP（26.21.59.131），完成后双击进入。以你 Radmin 列表里实际显示的为准——网络重建后地址可能变。

常见问题 FAQ

  1. 进服提示「版本不符 / 缺少 Mod」：确认你导入的是 Age of Engineering RCMS 1.5，不要用旧的 v1.4 / v1.3 或 CurseForge 原版 AoE。
  2. 启动器报「找不到 Java」：回到第一步重新安装 Java 8，并确认安装路径无中文；在 PCL2 设置里手动指定 C:\Program Files\Java\jre1.8.0_411\bin\javaw.exe。
  3. Radmin 列表里看不到主机：检查网络名是否大写 ALE_211、密码 123456 是否正确；退出 Radmin 重开；确认双方都在网络里。
  4. IPv6 方式也连不上：部分运营商分配了 IPv6 但封锁了出站端口，直接改用方式 B（Radmin VPN）即可。
  5. 游戏启动后闪退 / 卡在加载：在 PCL2 里把内存分配调到 4~6 GB；mod 多的整合包第一次进世界需要较长加载时间。
  6. 多人游戏列表里没有任何服务器：属正常现象，按上面步骤手动「添加服务器」填入地址即可。
