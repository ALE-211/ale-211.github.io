CS:GO 联机教程（和朋友开黑用）

先说在前面

别看到标题就去 Steam 商店搜 CS:GO——搜不到了。2023 年 9 月 Valve 把 CS:GO 直接下架，换成了 CS2。但老 CS:GO 没彻底死，想进我们这台服，得用下面这套办法把"老版本"调出来。

我们的服跑的就是原版 CS:GO（不是 CS2）。IPv6 直连地址：ale211.eu.org:27015；走 Radmin VPN 的话直接连主机虚拟 IP：26.21.59.131:27015。Radmin 网络名 ALE_211，密码 123456。

整个流程四步：装 CS2 → 切到 legacy 测试版 → 打开控制台 → connect 命令连服。Radmin VPN 那步和 MC 教程通用，需要的话翻 MC 教程第五步 就行。

第一步：装 CS2，然后切到 legacy 测试版

CS:GO 本身已经不能单独下载了，但 Steam 留了个后门：在 CS2 里选测试版分支，就能装回老版本。

  1. Steam 库里先装好 Counter-Strike 2（免费，没装的话商店直接搜）。
  2. 库里右键 Counter-Strike 2 → 属性。
  3. 切到 测试版 / Betas 标签页，"参与测试"下拉框选：
    csgo_legacy - Legacy Version of CS:GO
  4. 关掉属性窗口，Steam 会自动开始下载老版本文件（大约 13 GB，第一次等久一点）。
  5. 下完点绿色"开始"按钮，Steam 会弹个小框问你启动哪个版本，选 "Play Legacy Version of CS:GO"，别选成 CS2 了。

注意：切到 legacy 之后，你以后点"开始游戏"默认进的就是老 CS:GO。想回去玩 CS2，再到同一个地方把测试版改回"无 - 不选择任何测试版"即可。

第二步：打开开发者控制台

CS:GO 的控制台默认是关的，得手动开。连服务器全靠它。

  1. 进游戏主菜单，点左下角齿轮 设置。
  2. 切到 游戏设置 / Game 标签。
  3. 找到 "启用开发者控制台（~）"，选 是 / Yes。
  4. 按键盘左上角 ~（Tab 上面、Esc 下面那个波浪号键），能弹出黑底白字的控制台就成了。

按不出来？看看是不是被输入法占了，或者换个键位：在设置 → 键盘/鼠标里找"打开控制台"，改成你顺手的键。

第三步：连服务器

打开控制台，敲下面命令回车就行。和 MC 一样，先看自己有没有 IPv6：浏览器开 test-ipv6.com，显示 10/10 就走方式 A，否则走方式 B。

方式 A：IPv6 直连（推荐）

控制台里直接敲：

connect ale211.eu.org

回车，等个几秒钟右下角会显示正在连接，加载完就进服了。

方式 B：没有 IPv6，走 Radmin VPN

Radmin 的安装、加网络那套和 MC 完全一样（网络名 ALE_211，密码 123456），这里不重复了，直接看 MC 教程第五步。

加完网络后，主机的 Radmin 虚拟 IP 已经固定为 26.21.59.131，不用自己抄。控制台直接敲：

connect 26.21.59.131

如果以后开了服务器密码，命令格式是这样（注意中间分号）：

connect ale211.eu.org:27015; password 你的密码

常见问题

  1. 点"开始游戏"直接进 CS2 了，没让选版本：说明你没切到 csgo_legacy 分支，或者下完之后 Steam 自动更新回去了。回属性 → 测试版，重新选一次。
  2. connect 之后一直卡"正在连接"然后超时：先 ping 一下域名通不通。IPv6 直连不通就老老实实走 Radmin；Radmin 也连不上，确认你和主机都在 ALE_211 网络里、防火墙放行 Radmin。
  3. 按 ~ 没反应：控制台没开。回设置 → 游戏，确认"启用开发者控制台"是"是"；中文输入法状态下也可能吞键，切回英文再试。
  4. 提示"服务器在运行不同版本"（Disconnect: Server is running a different version）：你进的是 CS2 而不是 legacy 版。按第一步重新确认启动版本。
  5. 想玩 CS2 不想玩老 CS:GO 了：从Steam库中启动cs时选择cs2即可
  6. 找不到 CS:GO 商店页：正常，Valve 已经下架了，不要到处找安装包，就用上面的 legacy 分支方法。
